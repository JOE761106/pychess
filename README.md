project name : pychess

Hello . This project is chess in python. Its planned to be just like normal chess , the pieces were designed by me not by taking pictures online thats why they look bad lol.

And if your wondering yes special moves gonna be included , and this includes:
  (1)en passent 
  (2)castle 
  (3)draw - not a special move but every draw possible will be in game stalemate also included 

Of course just like normal chess if a piece is pinned to the king you wont be able to move it.

Additional features:
  (1)sound effect when in check
  (2)maybe background music will decide if yes or not
  (3)maybe title screen will think if yes or no
  (4)sound effect for doing a move 
  (5)if mate is commited a different sound

plans for piece movment:
  The proccess i plan is:
      First user clicks piece
      Second the program checks which piece is it
      Third program calculates the movement of the piece
      Fourth checks legal moves 
      Fifth if user clicks on illegal square the chosen piece is reset to none
      And finally if user does select legal square the piece will go there
